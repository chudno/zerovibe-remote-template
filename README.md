# Удалённая разработка сайта

Исходники сайта и история изменений хранятся в git этой рабочей папки. Сайт
работает на сервере владельца. Подключение и адрес сайта задаются на вкладке
«Сервер»; секреты в эту папку не записываются.

Сначала изучите сервер с помощью `remote-inspect`. `./deploy.sh` показывает
сухой прогон, `./deploy.sh --apply` создаёт резервную копию на сервере и
выкладывает файлы после сухого прогона.
