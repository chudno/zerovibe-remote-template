---
name: remote-db
description: Резервная копия MySQL и безопасные миграции на сервере.
---

До изменения схемы сделай дамп через `ssh server` и `mysqldump` в
`~/zv-backups` с уникальным именем, правами только для владельца (`umask 077`)
и проверь успешный код завершения. Учетные
данные вводятся человеком только через форму секретов проекта; не спрашивай их
в чате и не выводи. Не передавай пароль в аргументах команд, URL или git:
используй защищённый файл конфигурации MySQL на сервере либо стандартный ввод.
Если безопасный доступ или дамп не получились, схему не меняй. Применяй
миграции только через SSH, проверяй результат, коммить файлы миграций.

Файл конфигурации сайта с паролями (например `.env.php`) создавай на сервере
сразу с правами 600 (`umask 077`). Если веб-сервер после этого не может его
прочитать — 640. Шире не открывай: на общем хостинге его прочтут соседи.
