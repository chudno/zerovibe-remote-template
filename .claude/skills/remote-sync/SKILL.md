---
name: remote-sync
description: Безопасно выложить сайт на сервер клиента.
---

Узнай состояние сайта через `remote-info`. При `live: false` сначала установи
парольную защиту по `remote-protect`. При `live: true` предупреди владельца,
что изменения увидят посетители, и дождись его согласия в чате перед каждой
выкладкой. Сам переключатель «Сайт открыт» меняет только владелец во вкладке
«Сервер». Источник правды — git рабочей папки; перед выкладкой закоммить готовый
шаг. Не меняй файлы вне папки сайта; исключение — архив в `~/zv-backups`.

Используй `./deploy.sh --dry-run`, изучи список изменений и исключения. Затем
`./deploy.sh --apply`: скрипт повторно делает архив ВСЕЙ папки сайта на сервере,
проводит сухой прогон и только потом применяет rsync. Если архив, проверка пути
или сухой прогон не удались, остановись. `--delete` допустим только в папке,
полученной из `remote-info`, после успешного архива. Не снимай защиту при синхронизации.

После выкладки установи зависимости на сервере, если нужно, проверь сайт по
`remote-check` и сообщи результат человеку простыми словами.
